# Session — v0.11.0
**Date:** 2026-05-03
**Version:** 0.10.0 → 0.11.0

## What We Did

Made patient and clinic signup work end-to-end on the new schema, plus the surrounding UI standardization that goes with it.

### Reference data
- Pulled the PSGC tree from `psgc.gitlab.io/api` and seeded `ph_regions` (17), `ph_provinces` (81), `ph_cities` (1634), `ph_barangays` (42046)
- Loosened `ph_*` SELECT to allow `anon` so the signup pickers populate before login

### Mobile auth flow
- `app.json` scheme is now `lumenai` (matches the Vercel landing pages)
- `AuthUser` carries the new schema shape (first / middle / last / patient-only fields)
- `authStore.registerPatient(...)` writes per-field metadata so the `handle_new_user` trigger populates profiles + auto-generates `patient_code`
- `authStore.registerClinic(...)` invokes the new `clinic-signup` Edge Function, then auto-signs-in
- Login blocks `role=admin` on mobile
- Email verify + reset redirect to the Vercel landing pages
- `account-activated` and `reset-password` screens consume the deep-link hash via `expo-linking` and call `supabase.auth.setSession`

### UI standardization
- Floating-label `<Input>` is now the global default; supports `format='date'` / `'phone'` / `'doh-lto'`, `optional` flag, and `accentColor` override for role-based theming
- New `<Picker>` — searchable bottom-sheet modal with FlatList virtualization (smooth at 42K barangays)
- New `<InitialsAvatar>` — Teams-style up-to-2-letter avatar with a 12-color palette seeded for stability

### Patient signup polish
- Two-card form (Account / Profile)
- Sex limited to Male / Female
- Middle name labelled `(optional)`
- DOB and contact auto-format

### Role selector + theme separation
- Tab strip switches Patient / Clinic
- Patient = teal `accent`; Clinic = info `blue`. Theme accent flows through inputs, toggles, button, header logo, links

### Clinic signup
- 4-card form: Account / Facility / Location & Contact / Primary Contact Person
- PSGC pickers chain region → (province for non-NCR) → city → barangay; ZIP auto-fills from `ph_cities.default_zip`
- DOH LTO and phone use the new auto-format masks
- Edge Function `clinic-signup` (`verify_jwt=false`) runs the atomic create with rollback on any step failure
