# Session — v0.9.8
**Date:** 2026-05-01
**Version:** 0.9.6 → 0.9.8 (0.9.7 = Y16 JNI bridge from prior session portion; 0.9.8 = this session)

## What We Did

- Migrated foot isolation entirely from JS thread to Kotlin background thread (`UVCModule.kt`): Otsu threshold (256-bin, maximize between-class variance) + BFS flood fill → largest component + morphological closing (dilate 5px / erode 2px, ~3px net expansion with finger gaps filled)
- Added `buildIsolatedPng()` in Kotlin: ARGB_8888 Bitmap, transparent background for non-foot pixels, ironbow palette for foot pixels, PNG Base64 output
- Added `buildMaskedCsv()` in Kotlin: "0.00" for background, "%.2f" for foot pixels
- Removed auto-save from `processCapture()` — files are saved at JS bundle-save time when bundle code is known
- Added `savePngToDevice` and `saveCsvToDevice` as `@ReactMethod`s on Kotlin background thread
- Rewrote `captureProcessor.ts` — removed all JS isolation imports; uses native `isolatedPngB64` and `maskedCsvContent` from `NativeProcessResult`
- Redesigned `FootData` in `bundleStorage.ts`: separate `raw_image_b64`, `processed_image_b64`, `isolated_image_b64`, `csv_content` fields; bundle-code filenames (`${code}_L_raw.png`, `_L_processed.png`, `_L_isolated.png`, `_L_csv.csv`); raw JPEG stored bundle-only
- Updated `sessionStore.ts`: `leftRawB64`/`rightRawB64` added; renamed `leftImageB64`/`rightImageB64` → `leftProcessedB64`/`rightProcessedB64`
- Updated all three live-feed wrappers to extract and pass raw/processed/isolated B64 values to store
- Updated `PatientDetailsScreen.tsx` to pass full FootInput (raw/processed/isolated/csv/stats) to `saveBundle()`
- Updated `BundleDetailScreen.tsx`: three images per foot (UNPROCESSED | POST-PROCESSED | ISOLATED) at 160:120 aspect ratio; `onViewCsv` prop; CSV modal removed
- Built `CsvViewerScreen.tsx`: WebView HTML table; CELL_PX=44 (values readable); 256 ironbow CSS classes; `device-width` viewport; background cells dimmed
- Created thin csv-viewer route wrappers for clinic/patient/offline route groups; registered in layout files
- Updated all bundle-detail route pages to pass `onViewCsv` with router push
- Fixed `LOW_SIGNAL_MIN` in `ReadinessIndicator.tsx` from 6.0 → 2.5°C² (fixes "No Subject" false positive)
- Updated `footIsolation.ts` (JS-side): Otsu threshold + morphological closing mirrors Kotlin logic
